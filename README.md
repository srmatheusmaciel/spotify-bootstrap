# Clone do Layout Antigo do Spotify

Este projeto é uma recriação do antigo layout do Spotify, desenvolvido utilizando **Bootstrap**, **CSS** e **HTML**. O objetivo foi praticar a estruturação de páginas responsivas e a estilização com Bootstrap e Glyphicons.

## 📌 Tecnologias Utilizadas

- **HTML5**
- **CSS3**
- **Bootstrap** (CDN e arquivos locais)
- **Glyphicons** (para ícones)
- **npm.js**

## 📁 Estrutura de Pastas

```
📦 spotify-bootstrap
├── bootstrap
│   ├── css
│   ├── fonts
│   ├── js
├── imagens
├── estilo.css
├── index.html
```

## 🎨 Funcionalidades e Características

- **Layout Responsivo** com Bootstrap.
- **Ícones do Glyphicons** para botões e menus.
- **Organização de arquivos** para facilitar a manutenção.
- **Uso de npm.js (online)** para gerenciamento de dependências.

## 🚀 Como Executar o Projeto

1. **Clone o repositório**
   ```bash
   git clone https://github.com/srmatheusmaciel/spotify-bootstrap.git
   ```

2. **Abra o arquivo `index.html`** em um navegador.
